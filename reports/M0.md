# M0 — Repository bootstrap

## What was built

Empty engine skeleton that configures, builds, and runs smoke tests.

- `docs/PLAN.md` is the stage-1 plan. `DECISIONS.md` has no changes. `DESIGN.md` is headings only.
- CMake options `TILEMD_ARCHS` (default `80;90`) and `TILEMD_BUILD_TESTS` (ON). Device code gets `-lineinfo` in every config and `-O3` in Release. `--use_fast_math` is off unless `TILEMD_FAST_MATH=ON`.
- GoogleTest 1.15.2 via FetchContent. `cpu_smoke` checks the version string and the non-negative float bit ordering used by the displacement `atomicMax`. `gpu_smoke` launches a one-thread kernel, or skips when no device or no kernel image is available.
- `scripts/check.sh` (format, Release build, CPU tests) and `scripts/gpu_check.sh` (full suite, log under `reports/logs/`).
- GitHub Actions runs `scripts/check.sh` in `nvidia/cuda:12.4.1-devel-ubuntu22.04`. The image does not ship CMake ≥ 3.24 or clang-format 22, so the workflow installs `cmake` and `clang-format==22.1.8` with pip.
- `bench/scripts/collect_env.py` writes the environment JSON. The hostname is a SHA-256 digest.

## Deviations

- `.gitattributes` forces LF. Without it, `scripts/check.sh` breaks on Windows checkouts.
- On Windows, `scripts/check.sh` loads `vcvars64.bat` and uses Ninja. The Visual Studio generator stopped at "No CUDA toolset found" because the CUDA MSBuild files are not registered with Visual Studio. Ninja calls `nvcc` directly.
- Git Bash rewrites a `CL` value that starts with `/` into a fake path (`CL=/wd4819` became `C:/Program Files/Git/wd4819`). The script sets `MSYS2_ENV_CONV_EXCL=CL` before invoking `cmd.exe`.
- `reports/logs/M0_gpu_check.log` has the local username replaced with `USER`.
