# M4 — Performance foundation

## What landed

Neighbor rebuilds now stable-sort atoms by a 10-bit Morton code of the cell and permute every per-atom array. `gid` records the original index. Position, velocity, and force downloads scatter back to that index. Neighbors are sorted by global id, so the pair sum stays in the oracle's order.

The step still syncs with the host. Graphs, templated energy and virial, and the device-only rebuild flag are not in yet.

## Tests

`BUILD_DIR=build-m4 bash scripts/check.sh` configured, compiled the engine, and passed the two CPU tests (2026-10-19). The GPU suite was not repeated: the M3 radial-distribution and drift jobs are using this GPU. Those tests still have to pass on this binary before G2 or G3 can be claimed.
