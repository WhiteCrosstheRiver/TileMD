# M5 — Cluster-pair tiles

## What landed

`src/neighbor/cluster_list.cpp` builds the column grid and the cluster-pair list on the host. Columns are an x–y grid with about 32 atoms each when the count is left at zero. Atoms in a column are stable-sorted by z and padded to a multiple of 8. Padding uses type `-1` and does not enlarge the bounding box. A pair of clusters is kept when the periodic box distance is below the reach. The shift index stores the image in `{-1, 0, 1}` on each axis.

`ComputeTileForces` evaluates full-list Lennard-Jones on that list, in cluster order, and writes forces back in the original atom order. The GPU tile kernel is not in this commit. The atom-neighbor engine is unchanged.

## Tests

`BUILD_DIR=build-m5 bash scripts/check.sh` passed the CPU suite (2026-10-19). That includes the cluster-list tests and a 40-atom shifted-force comparison against the double-precision oracle. Tile efficiency on the melt, bytes per atom-step, and the speed comparison with M4 are not measured yet.
