# M6 — Fused single-kernel time step

## What is in

`reference/lj_reference.cpp` now steps the double-precision oracle with velocity Verlet and with leapfrog. Leapfrog keeps `v(t − dt/2)`. The conversion from an integer-time start is `v(−dt/2) = v(0) − ½ dt f(0) / m`. Integer-time velocity for comparison is `v(t) = v(t − dt/2) + ½ dt f(t) / m`. Positions wrap into the box and image counters record the periods.

The fused GPU kernel, the double-buffered `pos4` pair, and the removal of the force array are not in this tree.

## What was run

On 40 atoms, `dt = 0.005`, mass 1, for 100 steps, leapfrog and velocity Verlet stay within round-off. The largest position difference is `8.88e-16`. The largest integer-time velocity difference is `2.11e-15`. Image counters match.

Bytes per atom-step and the speed comparison with M5 are not measured. The 32k RDF and drift runs still occupy the RTX 3050, so the fused kernel has not been launched.
